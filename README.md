# Оптимизация системы для Dota 2 (Без прав администратора)

Этот проект содержит PowerShell скрипт для оптимизации игры Dota 2 без необходимости прав администратора. Скрипт автоматически находит установку Dota 2 через Steam и создает файл `autoexec.cfg` с оптимизированными настройками сети, инпута и графики для улучшения производительности и снижения задержек.

## Функции оптимизации

- **Сеть**: Устанавливает высокие значения rate, cl_interp 0, cl_cmdrate/updaterate 128.
- **Инпут**: Включает raw input, отключает input latency.
- **Графика**: Оптимизирует рендеринг, отключает некоторые эффекты для повышения FPS.

## Требования

- Операционная система: Windows 10/11
- PowerShell (стандартный)
- Установленный Steam с игрой Dota 2
- Интернет-соединение (не требуется для самого скрипта)

## Использование

1. Скачайте скрипт `boost_pc_dota2_no_adm_rul.ps1`.
2. Запустите PowerShell (права администратора не требуются).
3. Выполните скрипт: `.\boost_pc_dota2_no_adm_rul.ps1`.
4. Скрипт автоматически создаст или обновит файл `autoexec.cfg` в папке `Steam\steamapps\common\dota 2 beta\game\dota\cfg`.
5. Запустите Dota 2 – настройки применятся автоматически.

## Предупреждения

- **Резервное копирование**: Рекомендуется сохранить существующий `autoexec.cfg`, если он есть.
- **Перезагрузка**: Не требуется, изменения применяются при следующем запуске игры.
- **Ответственность**: Используйте на свой страх и риск. Автор не несет ответственности за возможные проблемы с игрой.
- **Совместимость**: Работает только если Dota 2 установлена через Steam в стандартной папке.

## Результат

После выполнения скрипт выведет отчет о статусе задач (SUCCESS или FAILED). Если все SUCCESS, оптимизация прошла успешно.
