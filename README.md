# Оптимизация системы для Dota 2

Этот проект содержит PowerShell скрипт для оптимизации системы Windows, направленный на улучшение производительности в игре Dota 2. Скрипт вносит изменения в реестр, отключает определенные функции и устанавливает ISLC для автоматического запуска.

## Функции оптимизации

- **Сеть**: Включает алгоритм Нагла, отключает задержки прерываний.
- **Видео**: Отключает MPO (Multi-Plane Overlay), включает игровой режим.
- **ISLC**: Скачивает и настраивает Intelligent Standby List Cleaner для автоматического запуска.
- **QoS**: Снимает лимиты на трафик.

## Требования

- Операционная система: Windows 10/11
- PowerShell с правами администратора
- Интернет-соединение для скачивания ISLC

## Использование

1. Скачайте скрипт `1` (или переименуйте в `optimize_dota.ps1` для удобства).
2. Запустите PowerShell от имени администратора.
3. Выполните скрипт: `.\1` (или `.\optimize_dota.ps1`).
4. После выполнения перезагрузите компьютер для применения изменений.

## Предупреждения

- **Резервное копирование**: Рекомендуется создать точку восстановления системы перед запуском.
- **Перезагрузка**: Обязательна для применения изменений в реестре.
- **Ответственность**: Используйте на свой страх и риск. Автор не несет ответственности за возможные проблемы.
- **Антивирус**: Некоторые антивирусы могут блокировать изменения в реестре или скачивание ISLC.

## Результат

После выполнения скрипт выведет отчет о статусе каждой оптимизации (SUCCESS или FAILED). Если все SUCCESS, оптимизация прошла успешно.
